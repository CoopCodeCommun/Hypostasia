# Documentation utilisateur

**Il n'y a pas, aujourd'hui, de documentation utilisateur à jour.**

Ce dossier n'en contient qu'une **archive gelée**, `archive-v2/`, écrite le
22 février 2026 pour la V2 du produit. Elle décrit une interface et un
vocabulaire que le produit n'emploie plus.

## Pourquoi elle n'est pas simplement corrigée

Ce n'est pas un rafraîchissement de quelques phrases : c'est le modèle même
qui a changé.

| L'archive dit | Le produit dit |
|---|---|
| **dossier** | **carnet**, et **base de connaissances** au-dessus |
| **page** | **note** |
| une page appartient à un dossier | une note appartient à N carnets, par une table de liaison qui porte ses catégories |
| l'arbre de dossiers à gauche | il a été retiré le 12 août 2026, avec le menu burger |
| les pastilles de marge | mortes le 10 août 2026 (R2) |

S'y ajoutent des écrans qui n'existaient pas — carnet, base de connaissances,
synthèses dirigées, wikis, sélection des preuves — et des mécanismes entiers :
l'ancrage par élément, la gouttière, le lecteur audio.

Réécrire ces six fiches demande de reprendre chaque écran devant le produit.
C'est un chantier, pas une retouche, et il n'a pas encore été fait.
