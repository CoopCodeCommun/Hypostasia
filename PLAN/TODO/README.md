# Notes d'intention — ce qui est décidé mais pas codé

> **Ce dossier ne tient AUCUN état d'avancement.** Trois documents seulement en
> tiennent un (`CHANGELOG/`, `PLAN/PASSATION.md`, la mémoire), et en ajouter un
> quatrième garantit qu'il périmera sans que personne ne le sache.
>
> Ce qu'on écrit ici, et rien d'autre : une **intention de conception** prise par
> le mainteneur, que le code ne porte pas encore. Chaque note dit **ce qui est
> voulu**, **ce que le code fait aujourd'hui**, et **ce qui casse si on ne le
> fait pas**.
>
> Une note dont l'intention est codée se **supprime** — elle n'a plus d'objet.
